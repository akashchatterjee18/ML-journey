# Clustering

## What is Clustering?

**Clustering** is an **Unsupervised Learning** technique used to group similar data points into **clusters**.

- Data points within the same cluster are **similar**.
- Data points belonging to different clusters are **dissimilar**.
- Clustering works **without labelled target/output data**.

### Example

Customer data can be divided into groups such as:

- High-spending customers
- Medium-spending customers
- Low-spending customers

---

## Why use Clustering?

Clustering is used for:

- Customer segmentation
- Image segmentation
- Anomaly detection
- Document/news grouping
- Recommendation systems
- Market segmentation
- Pattern recognition
- Exploratory Data Analysis

# 1. K-Means
**K-Means** is an **Unsupervised Learning** algorithm used to divide data points into **K clusters** based on their similarity.

- `K` = Number of clusters
- Each data point is assigned to the **nearest cluster centroid**.
- The algorithm tries to make points within the same cluster as similar as possible.
- It minimises the **Within-Cluster Sum of Squares (WCSS)**.

## How K-Means Works

The algorithm follows these steps:

1. Choose the number of clusters `K`.
2. Initialise `K` cluster centroids randomly.
3. Assign each data point to its **nearest centroid** using **Eucledian Distance**.
4. Recalculate the centroid of each cluster.
5. Repeat the assignment and centroid update steps.
6. Stop when the centroids no longer change significantly or the maximum number of iterations is reached.

---

### Note : For making the clusters and checking the "k" value, we use the Elbow Method.
---

## Elbow Method
1. Run K-Means for different values of K.
2. Calculate WCSS (Within Cluster Sum of Squares) aka Inertia for each K.

$$
\
WCSS = \sum_{k=1}^{K} \sum_{x_i \in C_k} ||x_i - \mu_k||^2
\
$$

3. Plot K against WCSS.
4. Find the point where the decrease in WCSS starts slowing down significantly.
5. This point is called the Elbow Point.
