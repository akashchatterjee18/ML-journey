# Heart Disease Prediction

A machine learning web application that predicts the likelihood of heart disease based on patient health parameters.

Built with Python, Scikit-learn, Pandas, and Streamlit.

## Live Demo

[Heart Disease Prediction App](https://heart-disease-prediction-by-ac.streamlit.app/)

## Features

* Interactive Streamlit interface
* Logistic Regression based prediction
* Feature scaling using StandardScaler
* Model loading using Joblib
* Real-time prediction from user inputs
* Deployed using Streamlit Community Cloud

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Joblib
* Streamlit

## Machine Learning

The application uses a trained **Logistic Regression** model.

The input data is scaled using the same `StandardScaler` used during model training before being passed to the model for prediction.

### Saved Files

| File                            | Description                          |
| ------------------------------- | ------------------------------------ |
| `Logistic Regression_heart.pkl` | Trained Logistic Regression model    |
| `scaler.pkl`                    | Trained StandardScaler               |
| `columns.pkl`                   | Feature columns used during training |



## How It Works

```text
User Input
    ↓
Create DataFrame
    ↓
Feature Scaling
    ↓
Logistic Regression
    ↓
Prediction
    ↓
Display Result
```

## Deployment

The application is deployed using Streamlit Community Cloud.

The deployed application loads the trained model, scaler, and feature-column information from the repository and uses them to generate predictions from user-provided inputs.
