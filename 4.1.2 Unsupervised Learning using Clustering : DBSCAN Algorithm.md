# DBSCAN

**DBSCAN (Density-Based Spatial Clustering of Applications with Noise)** is an **Unsupervised Learning** algorithm that forms clusters based on the **density of data points**.

- DBSCAN does **not require the number of clusters `K`** beforehand.
- It groups together points that are **closely packed**.
- It identifies points in low-density regions as **outliers/noise**.
- It can detect clusters of **arbitrary shapes**.

---

## How DBSCAN Works

DBSCAN mainly uses two parameters:

- `eps (ε)` → Maximum distance to consider points as neighbours.
- `min_samples` → Minimum number of points required to form a dense region.

The algorithm classifies points into:

1. **Core Point**
2. **Border Point**
3. **Noise Point**

---

## Core Point

A point is a **Core Point** if it has at least `min_samples` points within the `eps` radius.

```text
Number of points within ε ≥ min_samples
```

---

## Border Point

A **Border Point**:

- Does not have enough neighbouring points to be a core point.
- Lies within the `eps` neighbourhood of a **Core Point**.

Therefore, it belongs to the cluster but does not form the dense region itself.

---

## Noise Point

A **Noise Point** is a point that:

- Is not a Core Point.
- Is not reachable from any Core Point.

It is treated as an **outlier**.

---

## DBSCAN Parameters

### `eps (ε)`

Defines the maximum distance between two points for them to be considered neighbours.

- Small `eps` → Smaller/more clusters and potentially more noise.
- Large `eps` → Larger/fewer clusters and potentially less noise.

---

### `min_samples`

Defines the minimum number of points required within the `eps` neighbourhood to make a point a **Core Point**.

- Small `min_samples` → More points can become core points.
- Large `min_samples` → Fewer points become core points.

---

## Working of DBSCAN

1. Select an unvisited data point.
2. Find all points within its `eps` neighbourhood.
3. Check whether the number of neighbouring points is at least `min_samples`.
4. If yes, it becomes a **Core Point** and a cluster is created.
5. Expand the cluster by finding neighbouring points.
6. If a point does not have enough neighbours, it may be classified as a **Border Point** or **Noise**.
7. Continue until all points are visited.

---

## Advantages of DBSCAN

- No need to specify the number of clusters `K`.
- Can detect **arbitrarily shaped clusters**.
- Can identify **outliers/noise**.
- Does not require every point to belong to a cluster.
- Works well when clusters have clearly different densities.

---

## Disadvantages of DBSCAN

- Sensitive to the choice of `eps`.
- Sensitive to the choice of `min_samples`.
- Performs poorly when clusters have **very different densities**.
- Can struggle with high-dimensional data.
- Distance calculation becomes less meaningful in very high dimensions.

---

## K-Means vs DBSCAN

| Feature | K-Means | DBSCAN |
|---|---|---|
| Type | Centroid-based | Density-based |
| Need `K`? | Yes | No |
| Outlier detection | Poor | Good |
| Cluster shape | Mostly spherical | Arbitrary shapes |
| Main parameters | `K` | `eps`, `min_samples` |
| Uses centroids | Yes | No |
| Noise points | No | Yes |
| Scaling required | Usually | Usually |

---


### Important Note

**DBSCAN is a Non-Parametric Unsupervised Learning algorithm.**

- It does not assume any particular probability distribution.
- It does not require the number of clusters `K` beforehand.
- It uses density to identify clusters.
- Its main hyperparameters are `eps` and `min_samples`.

> **Non-parametric ≠ No parameters**
>
> DBSCAN has hyperparameters, but it does not assume a fixed parametric probability model.
