# Naive Bayes

## What is Naive Bayes?

Naive Bayes is a supervised machine learning algorithm used mainly for **classification**.

It is based on **Bayes' Theorem** and assumes that all features are **independent of each other** given the class.

## Bayes' Theorem

Bayes' Theorem calculates the probability of a class given the observed features.

$$
P(A|B) = \frac{P(B|A)P(A)}{P(B)}
$$

Where:

- $P(A|B)$ → Posterior Probability
- $P(B|A)$ → Likelihood
- $P(A)$ → Prior Probability
- $P(B)$ → Evidence

## Why is it called "Naive"?

It is called **Naive** because it makes a strong assumption that the features are conditionally independent of each other.

For example, if we are predicting whether a person is a hacker using:

- Internet usage
- Typing speed

Naive Bayes assumes that these features are independent given the class.

## How does Naive Bayes work?

1. Calculate the **Prior Probability** of each class.
2. Calculate the **Likelihood** of each feature for each class.
3. Calculate the **Posterior Probability** using Bayes' Theorem.
4. Compare the posterior probabilities of all classes.
5. Assign the class with the **highest posterior probability**.

## Naive Bayes Formula

For multiple features:

$$
P(C|X_1,X_2,\ldots,X_n)
\propto
P(C)\prod_{i=1}^{n}P(X_i|C)
$$

Where:

- $C$ → Class
- $X_1,X_2,\ldots,X_n$ → Features
- $P(C)$ → Prior Probability
- $P(X_i|C)$ → Likelihood

The denominator is omitted because it is the same for all classes when comparing them.

## Predicting a New Input

Now, we have a **new input** and want to find out whether the person is a **Hacker (1)** or **Non-hacker (0)**.

| Internet (hours/day) | Typing Speed (wpm) |
|---:|---:|
| 18 | 26 |

We will use **Naive Bayes** to calculate the probability of both classes and select the class with the higher probability.

## Step 1: Calculate Prior Probability

There are:

- 5 Hackers
- 5 Non-hackers
- 10 total observations

Therefore:

$$
P(Hacker) = \frac{5}{10} = 0.5
$$

$$
P(Non\text{-}hacker) = \frac{5}{10} = 0.5
$$

## Step 2: Calculate Mean and Standard Deviation

For continuous features, we can use **Gaussian Naive Bayes**.

The Gaussian probability density function is:

$$
P(x|C) =
\frac{1}{\sigma\sqrt{2\pi}}
e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

Where:

- $\mu$ → Mean
- $\sigma$ → Standard Deviation
- $x$ → New input value

### Hacker (1)

Internet:

$$
\mu_{H} = \frac{24+18+20+16+22}{5} = 20
$$

Typing Speed:

$$
\mu_{H} = \frac{56+30+34+28+32}{5} = 36
$$

### Non-hacker (0)

Internet:

$$
\mu_{NH} = \frac{12+10+8+6+14}{5} = 10
$$

Typing Speed:

$$
\mu_{NH} = \frac{22+18+16+12+20}{5} = 17.6
$$

## Step 3: Calculate Posterior Probability

For the new input:

$$
X = (18,26)
$$

For Hacker:

$$
P(Hacker|X)
\propto
P(Hacker)
\times
P(18|Hacker)
\times
P(26|Hacker)
$$

For Non-hacker:

$$
P(Non\text{-}hacker|X)
\propto
P(Non\text{-}hacker)
\times
P(18|Non\text{-}hacker)
\times
P(26|Non\text{-}hacker)
$$

After calculating the Gaussian probabilities:

$$
P(Hacker|X) > P(Non\text{-}hacker|X)
$$

Therefore:

$$
\boxed{\text{Predicted Class} = 1}
$$

### Final Prediction

The new person is predicted to be a **Hacker**.

## Types of Naive Bayes

| Type | Used For |
|---|---|
| Gaussian Naive Bayes | Continuous numerical data |
| Multinomial Naive Bayes | Count-based data, such as text |
| Bernoulli Naive Bayes | Binary features |
| Complement Naive Bayes | Imbalanced text classification |


### Note

Naive Bayes does **not require feature scaling** in the same way as distance-based algorithms such as KNN.

For **Gaussian Naive Bayes**, numerical features are modelled using their mean and variance.
