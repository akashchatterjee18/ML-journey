# Curse of Dimensionality

**Curse of Dimensionality** refers to the problems that arise when the **number of features (dimensions)** in a dataset increases.

## Why does it happen?

- Feature space grows **exponentially** with dimensions.
- Data becomes increasingly **sparse**.
- More data is required to represent the feature space properly.

## Main Problems

### 1. Data Sparsity
- Higher dimensions → **Sparser data**.
- Data points become far apart.

### 2. Distance Becomes Less Meaningful
- Difference between nearest and farthest points becomes relatively small.
- Affects distance-based algorithms:
  - KNN
  - K-Means
  - DBSCAN

### 3. Computational Complexity
- More features → More calculations.
- Increases **time and memory requirements**.

### 4. Overfitting
- More features provide more opportunities to fit **noise**.
- Higher dimensionality → Higher risk of **overfitting**.

### 5. More Training Data
- High-dimensional spaces require **exponentially more data** for effective learning.

## Example

If each feature has 10 possible intervals:

- 1D → `10` regions
- 2D → `10² = 100`
- 3D → `10³ = 1,000`
- 10D → `10¹⁰ = 10 billion`

## How to Reduce It?

- **Feature Selection** → Remove irrelevant/redundant features.
- **Dimensionality Reduction** → PCA, LDA, t-SNE, UMAP.
- **Regularisation** → L1, L2.

```text
Regularisation is a technique used to reduce overfitting by adding a penalty for model complexity.
- Prevents the model from assigning excessively large weights to features.
- Helps the model focus on the important features.
- Improves generalisation to unseen data.
Types:
- L1 (Lasso): Can make some feature weights zero → performs feature selection.
- L2 (Ridge): Shrinks feature weights towards zero but usually does not make them exactly zero.
```
