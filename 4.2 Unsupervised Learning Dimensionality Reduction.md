# Curse of Dimensionality

**Curse of Dimensionality** refers to the problems that arise when the **number of features (dimensions)** in a dataset increases.

## Why does it happen?

- Feature space grows **exponentially** with dimensions.
- Data becomes increasingly **sparse**.
- More data is required to represent the feature space properly.

## Main Problems

### 1. Data Sparsity
- Higher dimensions → **Sparser data**.
- Data points become far apart.

### 2. Distance Becomes Less Meaningful
- Difference between nearest and farthest points becomes relatively small.
- Affects distance-based algorithms:
  - KNN
  - K-Means
  - DBSCAN

### 3. Computational Complexity
- More features → More calculations.
- Increases **time and memory requirements**.

### 4. Overfitting
- More features provide more opportunities to fit **noise**.
- Higher dimensionality → Higher risk of **overfitting**.

### 5. More Training Data
- High-dimensional spaces require **exponentially more data** for effective learning.

## Example

If each feature has 10 possible intervals:

- 1D → 10 regions
- 2D → 10² = 100
- 3D → 10³ = 1,000
- 10D → 10¹⁰ = 10 billion

## How to Reduce It?

- **Feature Selection** → Remove irrelevant/redundant features.
- **Dimensionality Reduction** → PCA, LDA, t-SNE, UMAP.
- **Regularisation** → L1, L2.

```text
Regularisation is a technique used to reduce overfitting by adding a penalty for model complexity.
- Prevents the model from assigning excessively large weights to features.
- Helps the model focus on the important features.
- Improves generalisation to unseen data.
Types:
- L1 (Lasso): Can make some feature weights zero → performs feature selection.
- L2 (Ridge): Shrinks feature weights towards zero but usually does not make them exactly zero.
```

# Dimensionality Reduction

**Dimensionality Reduction (DR)** is the process of reducing the number of features/dimensions in a dataset while preserving as much important information as possible.

- Reduces the number of features.
- Helps reduce computational complexity.
- Can reduce noise and redundancy.
- Useful for visualising high-dimensional data.
- Helps reduce the **Curse of Dimensionality**.

---

## Types of Dimensionality Reduction

There are two major approaches:

### 1. Feature Selection

Select a subset of the **original features**.

Examples:

- Correlation-based selection
- Chi-Square
- Mutual Information
- Recursive Feature Elimination (RFE)

```text
Original Features
F1 F2 F3 F4 F5 F6 F7 F8

        ↓ Feature Selection

Selected Features
F1 F3 F6 F8
```

---

### 2. Feature Extraction

Creates **new features** by transforming the original features.

Examples:

- PCA
- LDA
- t-SNE
- UMAP

```text
Original Features
F1 F2 F3 F4 F5

        ↓ Feature Extraction

New Features
PC1 PC2
```

# PCA

**PCA (Principal Component Analysis)** is one of the most commonly used **Dimensionality Reduction** techniques.

PCA transforms the original features into a new set of features called **Principal Components**.

- Principal Components are linear combinations of the original features.
- They are arranged according to the amount of variance they explain.
- The first principal component explains the maximum variance.
- The second principal component explains the maximum remaining variance while being orthogonal to the first.

---

## Important Terms in PCA

### Principal Component

A principal component is a new axis/direction created from the original features.

```text
PC1 → Maximum variance
PC2 → Maximum remaining variance
PC3 → Maximum remaining variance
...
```

---

### Explained Variance

**Explained Variance** represents how much information/variance is captured by each principal component.

For example:

```text
PC1 → 60%
PC2 → 25%
PC3 → 10%
PC4 → 5%
```

PC1 and PC2 together explain:

```text
60% + 25% = 85%
```

Therefore, we can use PC1 and PC2 while retaining approximately **85% of the variance**.

---

## PCA Steps

1. Standardise the data.
2. Calculate the covariance matrix.
3. Calculate eigenvalues and eigenvectors.
4. Sort eigenvectors according to their eigenvalues.
5. Select the required number of principal components.
6. Transform the original data into the new feature space.

---

## Advantages of Dimensionality Reduction

- Reduces computational complexity.
- Reduces training time.
- Reduces memory usage.
- Helps visualise high-dimensional data.
- Can reduce noise and redundant information.
- Can help reduce overfitting.

---

## Disadvantages of Dimensionality Reduction

- Some information may be lost.
- Transformed features may be difficult to interpret.
- Some techniques can be computationally expensive.
- Choosing the correct number of dimensions can be difficult.
