# K-Nearest Neighbour (KNN)

## What is KNN?

K-Nearest Neighbour (KNN) is a supervised machine learning algorithm used for **classification and regression**.

It predicts the output of a new data point based on the outputs of its **k nearest neighbours**.

## How does KNN work?

1. Choose the value of **k** (number of neighbours).
2. Calculate the euclidean distance between the new data point and all training points and sort them

Euclidean Distance
###
$$
d(x,y) = \sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}
$$

3. Select the **k nearest neighbours**.
4. For **classification**, use the majority class among the k neighbours.
5. For **regression**, use the average (or weighted average) of the k neighbours' values.

## Choosing k
- Must be an odd number. 
- Small **k** → more flexible model, but can overfit.
- Large **k** → smoother decision boundary, but can underfit.
- **k** is commonly selected using cross-validation.

## Predicting a New Input

Now, we have a **new input** and want to find out whether the person is a **Hacker (1)** or **Non-hacker (0)**.


| Internet (hours/day) | Typing Speed (wpm) |
|---:|---:|
| 18 | 26 |

We will use **KNN** to find the **k nearest neighbours** of this new input and use majority voting to determine whether the person is a hacker.

We will use **Euclidean Distance**:

$$
d = \sqrt{(x_1-x_2)^2+(y_1-y_2)^2}
$$
