# Support Vector Machine (SVM)

**Support Vector Machine (SVM)** is a supervised machine learning algorithm used for **classification and regression**.

It finds the best **decision boundary (hyperplane)** that separates different classes while maximising the **margin** between them.

Example:

Suppose we have two classes:

- 🔵 Class 0
- 🔴 Class 1

SVM finds a boundary that separates the two classes.

### Hyperplane

For two features, the decision boundary can be represented as:

$$
w_1x_1 + w_2x_2 + b = 0
$$

Where:

- $w_1, w_2$ → Weights
- $x_1, x_2$ → Features
- $b$ → Bias

---

### Margin

The **margin** is the distance between the decision boundary and the nearest data points from each class.
SVM tries to **maximise the margin**.

The nearest data points to the decision boundary are called **Support Vectors**.

### Support Vectors

**Support Vectors** are the data points closest to the decision boundary.

They determine the position and orientation of the optimal hyperplane.



### Hard Margin SVM

Hard Margin SVM assumes that the data is **perfectly linearly separable**.

The constraints are:

$$
y_i(w^Tx_i+b) \geq 1
$$

The objective is to minimise:

$$
\frac{1}{2}||w||^2
$$

This maximises the margin.



### Soft Margin SVM

Real-world data may contain **overlapping classes or outliers**.

Soft Margin SVM allows some misclassification using a **slack variable** $\xi$.

Constraint:

$$
y_i(w^Tx_i+b) \geq 1-\xi_i
$$

Objective:

$$
\min \frac{1}{2}||w||^2 + C\sum_{i=1}^{n}\xi_i
$$

Where:

- $C$ → Controls the penalty for misclassification.
- $\xi_i$ → Slack variable.

### Effect of $C$

- **High $C$** → Penalises misclassification heavily → Smaller margin.
- **Low $C$** → Allows more misclassification → Larger margin.
