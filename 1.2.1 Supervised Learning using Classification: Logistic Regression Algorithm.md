# Logistic Regression

Logistic Regression is a **supervised machine learning algorithm** used primarily for **classification problems**.

Despite its name, Logistic Regression is generally used to predict the **probability of a categorical outcome**, rather than a continuous numerical value.

The most common application is **binary classification**, where the output has only two possible classes.

### Examples

- Spam or Not Spam
- Pass or Fail
- Disease or No Disease
- Fraud or Not Fraud
- Yes or No
- 0 or 1

## Why Not Use Linear Regression for Classification?

Linear Regression produces a continuous output:

$$
y = mx + b
$$

For classification, we need an output that represents a **probability between 0 and 1**.

For example:

$$
P(Y=1) = 0.85
$$

This means there is an **85% probability** that the observation belongs to class `1`.

Linear Regression can produce values outside the range `[0,1]`, such as:

$$
-0.4,\ 1.3,\ 2.5
$$

These values cannot represent probabilities.

Therefore, Logistic Regression uses a special function called the **Sigmoid Function**.

The **Sigmoid Function** converts any real-valued number into a value between **0 and 1**.

$$
\sigma(z) = \frac{1}{1+e^{-z}}
$$

Where:

$$
z = \beta_0 + \beta_1x
$$

Therefore:

$$
P(Y=1|x) =
\frac{1}{1+e^{-(\beta_0+\beta_1x)}}
$$

Where:

- $P(Y=1|x)$ = Probability that the observation belongs to class `1`
- $\beta_0$ = Intercept
- $\beta_1$ = Coefficient
- $x$ = Input feature
- $e$ = Euler's number

## Sigmoid Curve

The output of the sigmoid function always lies between:

$$
0 < P(Y=1|x) < 1
$$

The curve has an **S-shaped form**.

Important points:

- When $z \rightarrow -\infty$, probability approaches `0`.
- When $z = 0$, probability is `0.5`.
- When $z \rightarrow +\infty$, probability approaches `1`.

# Cost Function in Logistic Regression

Linear Regression commonly uses **Mean Squared Error (MSE)**.

However, MSE is not generally used as the standard loss function for Logistic Regression.

Logistic Regression uses **Log Loss**, also called **Binary Cross-Entropy Loss**.

For one observation:

$$
Loss =
-\left[y\log(p)+(1-y)\log(1-p)\right]
$$

Where:

- $y$ = Actual class
- $p$ = Predicted probability

For the complete dataset:

$$
J(\beta) =
-\frac{1}{n}
\sum_{i=1}^{n}
\left[
y_i\log(p_i)
+
(1-y_i)\log(1-p_i)
\right]
$$

The objective is to **minimise the Log Loss**.

# Optimisation of Logistic Regression

After finding the **Log Loss function**, our objective is to find the values of the model parameters $(\beta_0, \beta_1, \ldots)$ that **minimise the Log Loss**.

To minimise the Log Loss function, we use **Gradient Descent**.

## Gradient Descent

Gradient Descent is an optimisation algorithm used to minimise the cost function by iteratively updating the model parameters in the direction of the steepest decrease in cost.

The parameter update equation is:

$$
\beta_j \leftarrow \beta_j - \alpha \frac{\partial J}{\partial \beta_j}
$$

Where:

- $\beta_j$ = Model parameter
- $\alpha$ = Learning rate
- $J$ = Cost function (Log Loss)
- $\frac{\partial J}{\partial \beta_j}$ = Gradient of the cost function with respect to $\beta_j$

For Logistic Regression:

$$
\frac{\partial J}{\partial \beta_j}=\frac{1}{n}\sum_{i=1}^{n}(p_i-y_i)x_{ij}
$$

Therefore:

$$
\beta_j\leftarrow\beta_j-\frac{\alpha}{n}\sum_{i=1}^{n}(p_i-y_i)x_{ij}
$$

# Confusion Matrix

A **Confusion Matrix** is a table used to evaluate the performance of a **classification model** by comparing the **actual class labels** with the **predicted class labels**.

For binary classification, there are four possible outcomes:

|  | Predicted Positive | Predicted Negative |
|---|---:|---:|
| **Actual Positive** | **True Positive (TP)** | **False Negative (FN)** |
| **Actual Negative** | **False Positive (FP)** | **True Negative (TN)** |

## 1. True Positive (TP)

The actual class is **Positive** and the model correctly predicts **Positive**.

**Example:**  
Actual = Disease  
Predicted = Disease

---

## 2. True Negative (TN)

The actual class is **Negative** and the model correctly predicts **Negative**.

**Example:**  
Actual = No Disease  
Predicted = No Disease

---

## 3. False Positive (FP)

The actual class is **Negative**, but the model incorrectly predicts **Positive**.

**Example:**  
Actual = No Disease  
Predicted = Disease

This is also called a **Type I Error**.

---

## 4. False Negative (FN)

The actual class is **Positive**, but the model incorrectly predicts **Negative**.

**Example:**  
Actual = Disease  
Predicted = No Disease

This is also called a **Type II Error**.

---

The confusion matrix is the basis for calculating several classification evaluation metrics, such as:

- **Accuracy**
- **Precision**
- **Recall**
- **F1 Score**

# Classification Evaluation Metrics

## 1. Accuracy

**Accuracy** measures the proportion of total predictions that the model classified correctly.

$$
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
$$

### Example

From the confusion matrix:

- TP = 190
- TN = 40
- FP = 10
- FN = 10

$$
Accuracy = \frac{190 + 40}{190 + 40 + 10 + 10}
$$

$$
Accuracy = \frac{230}{250} = 0.92
$$

Therefore:

$$
Accuracy = 92\%
$$

---

## 2. Precision

**Precision** measures how many of the observations predicted as **Positive** were actually Positive.

$$
Precision = \frac{TP}{TP + FP}
$$

It answers:

> **Out of everything the model predicted as Positive, how many were actually Positive?**

### Example

$$
Precision = \frac{190}{190 + 10}
$$

$$
Precision = \frac{190}{200} = 0.95
$$

Therefore:

$$
Precision = 95\%
$$

**High Precision** → Few False Positives.

---

## 3. Recall

**Recall**, also called **Sensitivity** or **True Positive Rate (TPR)**, measures how many of the actual Positive observations were correctly identified by the model.

$$
Recall = \frac{TP}{TP + FN}
$$

It answers:

> **Out of all the actual Positive cases, how many did the model correctly identify?**

### Example

$$
Recall = \frac{190}{190 + 10}
$$

$$
Recall = \frac{190}{200} = 0.95
$$

Therefore:

$$
Recall = 95\%
$$

**High Recall** → Few False Negatives.

---

## 4. F1 Score

**F1 Score** is the harmonic mean of **Precision** and **Recall**.

$$
F1\ Score = \frac{2 \times Precision \times Recall}{Precision + Recall}
$$

### Example

If:

$$
Precision = 0.95
$$

and:

$$
Recall = 0.95
$$

then:

$$
F1\ Score = \frac{2 \times 0.95 \times 0.95}{0.95 + 0.95}
$$

$$
F1\ Score = 0.95
$$

Therefore:

$$
F1\ Score = 95\%
$$
